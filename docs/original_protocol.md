# Original Solo Leveling Study Protocol

This document describes the founding protocol that inspired the "Solo Leveling: Class 12 PCB Dungeon" project.

## Core Idea
Transform Class 12 NCERT PCB revision into a Solo Leveling RPG experience. The student is the "Player" who receives daily missions from the "System". Each chapter is a Dungeon Gate; each study session is a raid.

## Daily Schedule (Template)
- **05:00 – 05:30**: Wake up, morning ritual, physical training circuit
- **05:30 – 07:00**: Focus Block 1 + 2 (Physics — 50 min each with 10 min break)
- **07:00 – 07:10**: Break
- **07:10 – 08:00**: Focus Block 3 (Physics continued)
- **08:00 – 08:45**: Breakfast + rest
- **08:45 – 09:45**: Focus Block 4 + 5 (Chemistry — 50 min each)
- **09:45 – 11:15**: Focus Block 6 + 7 + 8 (Biology — 50 min each)
- **11:15 – 12:00**: Battle Exercises (1 per subject: MCQs, short answers)
- **12:00 – 13:00**: Lunch + rest
- **13:00 – 14:00**: Grimoire Review — log errors from morning session
- **14:00 – 17:00**: Rest / gap fill / free
- **17:00 – 18:30**: Night Review — flashcards (SRS due cards)
- **18:30 – 19:00**: Physical Quest (base circuit or mobility)
- **21:00 – 21:30**: Sleep log, reflection
- **22:00**: Lights out

## Honesty Oath
Before starting each session, the Player swears:
> "I will study as if no one is watching. I will not lie to the System. I will not skip quests without consequence. My potential is unknown. I will find it."

## Penalty System
- Skipped focus block → -40 XP
- Incomplete daily quest → -150 XP + Shadow Cleaning next day
- Emergency Lockout after 2 failed days in a week

## Rank Milestones
| Rank | XP Threshold | Meaning |
|------|-------------|---------|
| E    | 0           | Starting point — the weakest |
| D    | 2,501       | Awakened — the journey begins |
| C    | 7,001       | Raider — chapters falling |
| B    | 13,001      | Striker — strong enough to compete |
| A    | 20,001      | Elite — the top percentile |
| S    | 28,001      | Monarch — full System mastery |

## Weekly Boss Raids (Days 7, 14, 21, 28, 35, 42)
Every 7 days, the Player faces a Boss Raid: a 3-hour mock test taken in the Physics Wallah (PW) app. The result is self-reported. Raid reward: +500 XP + 90 minutes Monarch's Leisure Gate.
